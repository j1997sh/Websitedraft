# CPS homepage concept

Static, responsive homepage prototype based on the approved square-edged navy/blue design. This is an **unofficial concept**, not an official CPS website.

## Publish using GitHub Pages
1. Create a new public GitHub repository (e.g. `cps-homepage`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. GitHub will display the public Pages address once deployed.

## Before production
- Replace the CSS-drawn placeholder logo with the official licensed CPS logo asset.
- Replace stock image URLs and sample article headlines with real approved CPS content and correct article links.
- Connect newsletter form to an actual consent-aware email signup service. Currently it intentionally does not submit personal data.
- Connect search and navigation to final site URLs.
- Check image licensing, accessibility, privacy and performance.

The `reference.png` file is the original visual mockup and is not required for deployment.
